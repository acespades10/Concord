# Security

Concord is a portfolio MVP for one workspace and small teams. Use the
[production deployment guide](docs/production.md) for an internet-facing instance.
The local development configuration is not a production deployment.

Report vulnerabilities through this repository's **Security → Report a
vulnerability** feature when enabled. If unavailable, use the repository owner's
GitHub profile contact route to arrange private disclosure. Do not post live
credentials or exploitable details in a public issue.

Only the latest main-branch version is maintained. Production JavaScript
dependencies are audited in CI. Passing tests or dependency scans are not a
guarantee that the application is free of vulnerabilities.
